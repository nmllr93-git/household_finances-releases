# Household Finances: downloads

Installers for **Household Finances**, a private budgeting and net-worth app that keeps your data on your own phone, computer or home server.

## Download
Open **[Releases](https://github.com/nmllr93-git/household_finances-releases/releases)**:
- **Windows:** the newest `v…` release → `Household Finances Setup x.y.z.exe`. If SmartScreen warns, click **More info → Run anyway**. Updates install from inside the app (**Check for updates**).
- **Android:** the newest `Android …` release (listed below the Windows ones) → `HouseholdFinances-x.y.z.apk`. Open it on your phone and allow your browser to install apps when asked.

The other files on each release (`latest.yml`, `.blockmap`) are used by the Windows app's update check. You can ignore them.

## Privacy
Your financial data never leaves your device or your own server. See the **[Privacy Policy](PRIVACY.md)**.
